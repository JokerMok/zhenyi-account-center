# 本地实际验收结果

日期：2026-10-20。环境：macOS ARM64、Node.js 25.9.0、Docker 29.5.2、PostgreSQL 17、Casdoor v4.22.0 官方 Darwin ARM64 包。范围仅限本机项目，未操作线上数据或其他产品仓库。

## 已实现并验证

| 范围 | 实际结果与证据 |
| --- | --- |
| 初始化与版本 | 官方发布包 SHA-256 与发布页一致；隔离的新身份库中验证了随机初始管理员密码和授权码签发。初始化文件只在首次导入，后续重启不覆盖用户配置。 |
| 统一身份 | 浏览器实际注册了合成用户 A、B；账号中心、拼豆和录屏示例均通过标准 OIDC 授权码建立独立会话。自动化校验同一 issuer + subject 对应同一 UID。 |
| 登录安全 | state 错误 / 回调重放、真实签名但 nonce 错误、错误签名、错误 audience、过期 token 均被拒绝。PKCE S256 的实际授权码交换已完成。 |
| 账号安全入口 | 浏览器重新认证后进入 Casdoor 原生账户页，确认对应 A 的资料、编辑密码与安全设置入口；未执行真实密码修改或未配置的邮件发送。 |
| 权限隔离 | 消费者不能访问运营 API；伪造 user_id、另一用户预占、跨产品密钥与 token 均被拒绝。权益数据库角色不能连接 Casdoor 库；示例数据库角色不能读权益表或其他应用会话；示例环境不含管理凭据或另一产品密钥。 |
| 会员 | 管理员连续续期从较晚到期日累计；会员到期后仍能重新登录，高级功能返回拒绝。浏览器通过运营页给 A 开通 7 天拼豆会员，录屏仍未开通。 |
| 并发与幂等 | 3 次额度同时收到 12 个不同预占，3 个成功、9 个拒绝，无负数。8 个相同请求只生成一条预占；重复确认、返还只产生一次状态与流水变更。 |
| 超时与周期 | 过期预占经可执行释放机制回收，重复释放不增加次数；按日 / 按月同周期只发一个桶，测试功能验收后停用。所有桶 held 与未确认预占分摊守恒。 |
| 兑换 | 并发争抢一个限领码只产生一条领取；重复领取不重复发放，停用和次数限制生效。浏览器实际创建 5 次拼豆兑换码，并由消费者页面兑换成功。 |
| 两个示例 | 浏览器分别完成拼豆与录屏的成功任务、预占后失败释放、确认后失败返还。拼豆成功一次后从 3 → 2，录屏成功一次后从 2 → 1；失败恢复不再减少余额。产物由后端生成。 |
| 身份切换 | 录屏从 A 切换并注册登录 B 后，显示 B 自己的 2 次额度与空任务列表，没有 A 的结果或历史。 |
| 退出 | 自动化分别验证当前产品退出保留其他会话；从中心与独立示例发起全局退出，其他产品会话与上游 token 均失效，全部业务会话被删除。 |
| 管理记录 | 运营接口记录操作者、时间、原因和前后值；数据库触发器拒绝修改 / 删除权益流水与审计。 |
| 订阅核对 | Casdoor 真实管理订阅经服务端读取生效，重复核对不重复赠送；暂停订阅后对应投影和未用赠送失效。未使用前端返回页判定支付。 |
| 官方测试支付 | `npm run test:payment` 使用本机 Casdoor 官方 Dummy 提供者，实际执行 PlaceOrder → PayOrder → 官方 notify-payment → Paid → Active 订阅 → 权益 3 → 8。重复通知与核对后仍为 8。验收后暂停合成订阅，停用套餐和定价、解除支付提供者绑定并收回投影。没有真实资金。 |
| 持久化与恢复 | 停止并启动本项目所有服务后，账号稳定 ID 与 10 张业务表数量一致，原有账号可再次完成真实 OIDC 登录。备份实际恢复到新建的两个隔离数据库，账号 ID 和相同业务表数量对照一致，未覆盖运行库。 |
| 构建 | TypeScript 检查与 Vite 打包完成。存在约 503 KB 的入口包体积提示，不影响本地运行；没有因此做无关拆包重构。 |
| 本机监听 | 检查 Casdoor 仅监听 127.0.0.1:5300；通过配置阻止上游默认 RADIUS 随机 UDP 监听。数据库与三个应用均只绑定回环地址。 |

自动化关键业务结果：**20 项通过，0 失败**。原始运行日志保存在被 Git 忽略的 `.local/critical-test.log`；官方 Dummy 测试结果与日志在 `.local/dummy-payment-result.json`、`.local/payment-test.log`。这些结果证明对应本地场景，不能外推为生产或真实商户验收。

## 需要外部配置

- 邮件、短信、微信登录未配置；当前使用 Casdoor 用户名 / 密码。找回密码需要提供者配置，不能声称已经可用。
- 支付宝、微信、Stripe 等真实商户与其沙箱没有配置、没有交易测试。官方 Dummy 仅为本机模拟，不证明真实支付网关、退款或异步通知可靠性。
- 服务器、DNS、HTTPS、备案与真实产品回调需要后续授权配置。本轮只交付 Linux / Caddy / systemd 模板。

## 实际未完成或未验收

- Casdoor 容器镜像因 registry 连接失败未拉取，manifest 架构未获取；已用校验过的原生发布包运行。Docker-Casdoor profile、Linux 原生包与升级回退尚未运行验证。
- 真实拼豆 / 录屏仓库没有接入；这里只验证两个独立演示后端。
- 中心未实现 webhook 接收器和推送式 back-channel logout。订阅采用受信任服务端查询、5 分钟轮询与手动核对；全局退出通过中心会话撤销和 Casdoor 令牌撤销生效。
- 已实现响应式样式并在实际桌面浏览器检查；未进行真实手机设备验收。
- 消费者中心展示最近 100 条记录，运营流水 API 支持 limit/offset；新版运营用户、兑换码、流水支持真实分页与总数，未做大规模用户性能验证。
- 本地浏览器生成 / 导出不能依靠按钮或服务端扣次绝对防绕过，限制见接入指南。
