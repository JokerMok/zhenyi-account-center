# 消费者跨站登录修复验收（2026-10-22）

根因：产品与个人中心拥有独立会话，但安全/兑换原先直接打开中心页面；中心401只显示欢迎页。中心授权事务只保存mode，回调依赖共享产品Cookie，丢失tab并存在多标签覆盖。公开原生身份页默认应用仍是built-in。产品还向所有消费者显示后台链接。

本次修复：产品后端签发可信消费者导航上下文，中心自行OIDC建会话；预期UID、白名单product/tab逐次绑定，Cookie按state区分。账号不一致明确停止；普通授权不强制重新登录，切换才强制。原生消费者默认应用及注册/找回/资料返回修正；资料弹窗会话轮换后的CSRF同步，旧身份写操作拒绝。产品菜单移除后台；原生管理代理增加真实管理员边界，不只依赖隐藏入口或HTTP200错误体。

公网实际通过：全新无中心/管理员会话浏览器从拼豆注册；拼豆→security自动授权同UID→返回→redeem；刷新、多标签逆序完成、取消回调重试；两个消费者的作品/身份隔离与不一致处理；当前产品/中心退出、显式切换、同UID全部产品退出。消费者请求业务用户列表、发权益、修改配置及原生用户列表均401。用户独立登录管理员后实际查看/admin、业务产品和原生用户列表正常。
