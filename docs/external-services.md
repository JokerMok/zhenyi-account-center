# 外部服务配置与验证清单

全部使用 Casdoor v4.22.0 原生配置页面与后端逻辑。管理入口 http://localhost:5300/providers 、http://localhost:5300/applications 、http://localhost:5300/syncers 。本机未接入真实商户或员工系统。保存不是验证成功；缺项在中心完整管理页读取实际提供者配置后显示。已保存的敏感配置只由原生权限和脱敏接口处理，中心状态接口不返回密钥。

| 能力 | 最少需要提供／配置 | 原生验证与回调 | 当前边界 |
| --- | --- | --- | --- |
| 邮件与找回 | SMTP主机／端口、TLS方式、发信地址、授权密码；或目标邮件提供者凭据 | 提供者详情测试发送，真实邮箱收信后验证找回；邮件验证码走原生verification API | 未配置；没有伪造发送成功 |
| 短信与短信MFA | 服务商账号密钥、签名、模板、国家／地区和接收测试号码 | 提供者测试、注册／找回／MFA实际收码 | 未配置 |
| 微信及其他OAuth | 精确提供者类型、应用ID／密钥、平台批准的回调域名 | 官方OAuth回调为 `CASDOOR_URL/callback`；以提供者详情显示地址为准，提供者绑定到具体应用；完成授权再核对subject | 未配置；不同微信应用类型不可混用 |
| 支付 | 具体支付提供者、商户／应用号、密钥或证书、签名算法、测试环境与公网通知条件 | `/api/notify-payment/consumers/支付标识`；具体提供者按原生生成的notify URL；不从浏览器return判定Paid | 仅Dummy已验证；真实收费开关关闭，真实退款未验证 |
| 外部存储 | 目标服务、bucket／endpoint／region／访问凭据和URL策略 | 原生资源上传、授权读取、删除；验证读写和权限 | 本地文件存储上传／读取通过；云存储未接 |
| Captcha／推送／通知／日志 | 所选服务的站点键、密钥、接收目标和访问策略 | 对应提供者详情或绑定到应用后的实际触发操作 | 配置页面保留；未逐服务验证 |
| LDAP／AD目录 | 目录地址、Base DN、bind DN／密码、属性映射、可信TLS CA | 组织LDAP配置与同步；使用专用组织，先预览映射 | 本地LDAP／LDAPS服务端绑定搜索通过；真实目录导入未接 |
| 数据库同步 | 独立源数据库、只读账号、表与字段映射、可信主机 | Syncer测试连接／Run；再次Run验证幂等 | 独立本机PostgreSQL源已通过；真实业务源未接 |
| SAML联合 | 外部IdP/SP元数据、entity ID、ACS、签名证书、属性映射 | 原生元数据及 `/api/acs`；本机测试IdP签名响应已验，应用启用c14n10以兼容测试SP | 外部联合未接 |
| Kerberos | 域、KDC、SPN、keytab、持有票据的客户端 | 原生Kerberos登录入口 | 未配置 |
| WebAuthn／Passkey | HTTPS可信域或localhost、支持的浏览器与系统认证器／安全密钥 | 账号安全→注册→真实用户硬件确认→登录 | 需要用户／硬件确认；未伪造验收 |
| 人脸／钱包／扫码 | 对应设备、钱包或原生提供者配置及用户授权 | 原生登录方式；需要用户确认的动作由用户执行 | 未启动摄像头或签名钱包 |
| 远程智能体／MCP／站点代理 | 目标URL、授权、工具服务、端口和访问策略；按目标需要另配模型供应商 | 原生Server工具同步／调用、Agent／Entry／Site实际访问；避免本机无控制开放监听 | 原生MCP管理API作用域和工具调用通过；外部代理／模型工具未接 |

没有必须一次性提供以上所有资料：只需为准备启用的提供者配置。缺少真实商户、目录或模型账户时，其他身份与权益功能可正常使用。

独立A2A协议、独立LLM模型管理／推理未在固定源码中发现，不属于“等待API Key就能启用”的功能，见固定版本证据清单。
