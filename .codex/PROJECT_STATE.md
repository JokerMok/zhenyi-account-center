## 关键决策
- Casdoor 负责身份与原生订阅 / 支付事实，权益服务独立数据库，不写 Casdoor 表。
- issuer + subject 映射统一 UID；每个产品自己的 HttpOnly 会话，不共享父域高权限 Cookie。
- 权益通过受信任服务端查询核对订阅；免费额度按 once / UTC daily / UTC monthly，赠送额度独立到期。
- Docker 镜像渠道失败，按授权改用官方原生 Casdoor，不改上游源码。
